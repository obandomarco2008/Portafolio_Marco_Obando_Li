Veterinaria Aserrí

Aplicación de escritorio en C# · 2026

Aplicación de escritorio para gestionar una veterinaria. Los usuarios inician sesión, y el administrador controla las cuentas y las mascotas registradas. Los datos se guardan en MongoDB Atlas.

  • Inicio de sesión y registro de usuarios, con roles de administrador y cliente
  • Panel de administrador para ver usuarios y mascotas, buscar, modificar y eliminar
  • Gestión de mascotas con nombre, tipo de animal, raza, edad, peso y dueño
  • Base de datos en MongoDB Atlas con colecciones de usuarios y de mascotas
  • C#
  • Windows Forms
  • MongoDB Atlas
